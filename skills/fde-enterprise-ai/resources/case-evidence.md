# 案例证据与复用边界

- 原作者/实施者；我们在项目中的实际角色：
- 案例类型：概念演示 / 可运行原型 / 亲历口述 / 他人转述 / 宣传视频 / 有运行记录的实际项目。
- 原文或材料定位：
- 客户问题、原有流程、输入与输出：
- 展示了什么；没有展示什么：
- 效果数字、测量周期、基线、样本、成本、质量和证据：
- 尚待核实：
- 客户授权、匿名化、展示范围和复用许可：
- 可迁移的流程结构：
- 必须重新验证的数据、规则、系统权限和使用者：

## 面向客户的表述

“这是【作者/团队】的【案例类型】。它展示了【可证实的部分】；【上线/收益等】尚无可核验材料。我们拟用你们允许的样本验证【具体假设】。”

未获授权、含敏感信息或归属不清的材料，不进入对外案例库；可以用明确标注的合成样本展示方法。不得把共享案例说成自己的交付业绩。
