# 决策规则速查 — FDE 企业 AI 落地

| 能力 | 一句话规则 |
|---|---|
| 把模糊诉求变成可核对需求 | 先从客户原话和最近一次真实任务开始，把整理结果交回客户核对。 |
| 选择可验证的试点切口 | 用有样本、有负责人、结果可观察的单一场景验证一个业务假设。 |
| 将专家经验蒸馏成 SOP 或 skill | 把专家判断写成有输入、分支、输出和异常处理的步骤，并用新样本核对。 |
| 选工具并连接现有系统 | 从现有系统和具体约束出发，比较可运行路径，再验证数据流和连接条件。 |
| 以证据和阶段合作建立信任 | 用相关证据回答客户疑虑，限定当期投入、交付物和下一阶段条件。 |
| 用业务指标核算试点价值 | 先统一基线、质量、成本和周期，再给可复算的效果估计与验收口径。 |
| 完成交付并推动实际采用 | 责任有人承接、使用者能独立完成任务、出错有人接管，才具备持续采用条件。 |
| 设计面向角色与行动的工作台 | 围绕业务对象、状态、证据和下一步行动设计工作台，减少翻消息和切工具。 |
| 沉淀可维护的行业资产 | 区分共性、配置与定制，记录验证状态和版本，迁移时重验差异。 |
| 把市场与渠道信息变成行动清单 | 先定义来源、对象与时效，再把可追溯信息转成有负责人和期限的跟进。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
